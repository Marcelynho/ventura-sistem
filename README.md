# Ventura System

Sistema de gestão desenvolvido para a Óticas Ventura.

## Objetivo

O Ventura System foi criado para gerenciar toda a operação da Óticas Ventura em um único sistema.

## Funcionalidades

- Dashboard
- Cadastro de Clientes
- Pedidos
- Ordem de Serviço (OS)
- Financeiro
- Caixa
- Histórico
- Recibo de Atendimento
- Configurações

## Tecnologias

- HTML5

- JavaScript
- Firebase
- GitHub Pages
