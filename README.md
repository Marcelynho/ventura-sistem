# Ventura System

Sistema de gestão desenvolvido exclusivamente para a Óticas Ventura.

## Objetivo

O Ventura System foi criado para centralizar toda a operação da Óticas Ventura em um único sistema, facilitando o controle de clientes, pedidos, financeiro, caixa e histórico de atendimentos.

O projeto tem como foco um sistema profissional, simples de usar e com visual premium.
